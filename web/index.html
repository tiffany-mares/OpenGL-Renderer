cube

The OpenGL-Renderer demo, compiled to WebAssembly — single-threaded and browser-paced, on purpose.

Click the cube to give it keyboard focus, then: Space pauses the spin  ·  ← → yaw  ·  ↑ ↓ pitch.

This build strips the two systems the project is actually about — the frame pacer (no high-resolution sleep or busy-spin on a browser main thread; requestAnimationFrame owns the frame clock) and the threaded render (Emscripten's offscreen-canvas paths don't support GLFW) — so every number below comes from the native Windows build: full writeup on GitHub.
